## Summary

- An **indexer** lets you write `book["Ali"]` on your own class, as with a list
  or a dictionary.
- **C#:** `public T this[K key] { get; set; }`. **Python:** `__getitem__` and
  `__setitem__`.
- Python has more hooks: `__len__` for `len(obj)` and `__contains__` for `in`.
  C# uses an ordinary `Count` property instead.
- Choose what a missing key does: return a default (as here) or throw like a
  dictionary (`KeyNotFoundException` / `KeyError`).
