## Summary

- Old code still compiles or runs in many cases, but it is not how you should
  write new code.
- **C#:** `ArrayList` and `Hashtable` (untyped) → `List<T>` and
  `Dictionary<K, V>`; `String.Format("{0}", x)` → `$"{x}"`; `csc.exe` → the
  `dotnet` CLI; .NET Framework → modern .NET.
- **Python:** Python 2 (`print "x"`, `raw_input`, `xrange`, `/` on integers
  truncating) → Python 3; `%`-formatting → f-strings; `os.path` → `pathlib`.
- AI assistants sometimes produce old styles because a lot of old code exists.
  Recognize them and ask for the modern version.

## The same program, old and new

Old style:

<Pair id="old-code/old-style">
  Both still run. `ArrayList` accepts any object, so `42` went in next to a name
  and every read needs a cast that can fail at run time. `String.Format` and `%`
  match placeholders by position, which gets error-prone with many values.
  `os.path` works on plain strings.
</Pair>

Modern style:

<Pair id="old-code/modern">
  `List<string>` rejects `42` at compile time. Interpolation and f-strings put
  each value where it appears. `pathlib` paths are objects with attributes such
  as `suffix`.
</Pair>

Python 2 reached its end of life in 2020, but its code is still on the web and
in old books. Much of it doesn't even compile in Python 3:

## Other old C# you may see

<Note type="history" title="csc.exe and .NET Framework">
  Old instructions compile with `csc.exe Program.cs` from a "Developer Command
  Prompt" and target **.NET Framework** 4.x, which only runs on Windows and gets
  no new C# features. Modern .NET (5 and later) runs on Windows, macOS and
  Linux; you create and run projects with `dotnet new` and `dotnet run`
  (chapter 1).
</Note>

<Note type="history" title="Destructors / finalizers">
  `~Student() { … }` is a finalizer. Old material presents it as the place to
  clean up; in practice it runs at an unpredictable time, if at all. Use
  `IDisposable` and `using` (chapter 15). Python's `__del__` has the same
  problem — use `with`.
</Note>

<Note type="history" title="The old Main method">
  Before C# 9, every program needed `class Program { static void Main(string[]
  args) { … } }` and a `namespace { … }` block around it. Top-level statements
  and file-scoped namespaces (C# 10) do the same with less code.
</Note>
