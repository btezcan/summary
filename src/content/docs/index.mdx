This is a review and reference guide that teaches each concept in **C# and
Python side by side**: C# on the left, Python on the right. It is not a first
programming course. Use it to review a topic before a lab or an exam, to look up
syntax, and to understand *why* the two languages behave differently.

## How to use this guide

- **Read the Summary first.** Every chapter starts with the few points you must
  remember. If they're all familiar, jump to the exercises.
- **Predict before you reveal.** Decide on your answer to each "Predict the
  Output" exercise before opening it. A wrong guess teaches you more than
  reading the answer.
- **Run the code yourself, in both languages.** Change a value and predict the
  new output. The chapter [Getting Started](/getting-started/) shows how.
- **Type, don't copy.** Typing an example makes you notice every detail.
- **Use the cheat sheet** for quick lookups, and print it before an exam:
  [Cheat Sheet](/cheat-sheet/).

## Why two languages

C# is **statically typed** and **compiled**: the compiler checks types before the
program runs. Python is **dynamically typed** and **interpreted**: names and
types are checked while it runs. Seeing the same idea expressed both ways makes
the idea itself clearer — what a type is, what a reference is, what an exception
is — and shows which behavior belongs to the concept and which to one language.
